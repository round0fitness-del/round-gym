# نظام جولة اللياقة

نظام إدارة النادي: الأعضاء، الاشتراكات، الحضور بـ QR، العملاء اليوميون والمحتملون، صندوق المال، جدول الحصص، حسابات المتدربين والمدربين.

## المحتوى
- `server.js` الخادم (Node.js بدون أي مكتبات خارجية).
- `public/` واجهة النظام.
- البيانات تُحفظ في ملف `db.json` داخل مجلد البيانات، مع نسخة احتياطية يومية لآخر 30 يوماً في `backups/`.

## التشغيل
```
ADMIN_PASSWORD=كلمة-مرور-قوية node server.js
```
ثم افتح `http://localhost:3000` وادخل باسم المستخدم `admin`.

## متغيرات الاستضافة
| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور المدير الرئيسي (إلزامي). تغييره يغيّر كلمة المرور. |
| `ADMIN_USERNAME` | اسم مستخدم المدير، الافتراضي `admin`. |
| `DATA_DIR` | مجلد البيانات. على Railway يُستخدم مسار الـ Volume تلقائياً. |
| `PORT` | تضبطه الاستضافة تلقائياً. |

## الأدوار
- **مدير:** كل شيء.
- **استقبال:** الأعضاء والاشتراكات والحضور والتحصيل وإغلاق الوردية، بدون الاسترداد والمصروفات والصندوق والإعدادات وبيانات التدريب الشخصي.
- **محاسبة:** الفواتير والتحصيل والاسترداد والأقساط والمصروفات والصندوق والورديات والتقارير، بدون البيانات الصحية والتدريب الشخصي.
- **مدرب:** يدخل برقم جواله، ويرى متدربيه وحصصه فقط.
- **متدرب:** يدخل برقم جواله، ويرى بطاقته واشتراكه وجدوله فقط.

## سجل العمليات
يسجّل الخادم تلقائياً العمليات الحساسة (تعديل الأسعار، الخصومات، الإلغاء، الاسترداد، خصم الجلسات، إغلاق الورديات، حسابات الموظفين، الإعدادات) مع اسم المنفّذ ووقته. يطّلع عليه المدير فقط من صفحة «سجل العمليات».

## الموقع الإلكتروني
- الصفحة الرئيسية للنطاق `/` هي موقع النادي التسويقي، والنظام على `/app`.
- يعدّل المدير المحتوى من صفحة «الموقع الإلكتروني» في النظام: الشرائح والعروض والبرامج وصور المدربين والمعرض والآراء والتواصل، مع إظهار أو إخفاء كل قسم.
- الأسعار والجدول والمدربون تُسحب من النظام تلقائياً.
- طلبات «ابدأ بزيارة تجريبية» تصل إلى «العملاء المحتملون» بمصدر «الموقع الإلكتروني».
- الصور المرفوعة تُحفظ في مجلد `uploads` داخل مجلد البيانات.
